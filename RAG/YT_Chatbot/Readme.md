# YouTube RAG Chatbot 🎥🤖

A Streamlit-based Retrieval-Augmented Generation (RAG) chatbot that answers questions using YouTube video transcripts.

## Features
- YouTube transcript extraction
- Semantic search using FAISS
- LLM-powered answers (Ollama)
- Streamlit UI

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
